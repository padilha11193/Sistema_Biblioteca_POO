# Sistema_Biblioteca_POO
Sistema de biblioteca virtual, com cadastro e exclusão de livros, sistema de busca, empréstimo e devolução de títulos cadastrados.

# Funcionalidades
- Cadastro de livros com base em:
  - Título;
  - Autor;
  - Número de Páginas;
  - Condição de empréstimo;
- Edição de livros cadastrados;
- Exclusão de registros;
- Sistema de empréstimo e devolução;
- Consulta de títulos cadastrados;
